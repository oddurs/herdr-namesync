Both leaders show the product before describing it. iurysza has a banner and a demo video; qu8n has a before/after block. namesync has neither, and the thing it does best -- a name **changing** when the work changes -- is invisible in static text.

An asciinema cast or a short GIF of the sidebar over a few minutes of real work: a name lands, the work moves on, the name follows, and a hand-set name sits still while the one beside it updates. That last beat is the entire argument and it takes about eight seconds to watch.

Cheap alternative if recording is a nuisance: a fenced block showing the same workspace at three times, which is most of the value for none of the effort.

Done when: the first screen of the README contains something a reader can look at rather than parse.

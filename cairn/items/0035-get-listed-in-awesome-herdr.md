awesome-herdr (★186, updated daily) is the ecosystem's curated index and the main discovery path that is not the raw marketplace. It already lists six renamers under 'Workspace and multi-session management', including two that namesync directly competes with.

The marketplace index is automatic -- `topic:herdr-plugin` plus a manifest, both of which namesync already has, which is why it is indexed at ★0. awesome-herdr is curated, so it needs a pull request and a one-line description that earns the slot.

That one line is the hardest writing in this milestone. It sits in a table beside six alternatives and has to distinguish namesync in about fifteen words.

Depends on the positioning (0026) and reads better after the rename (0027) and a release (0033).

Done when: a PR is open against yigitkonur/awesome-herdr with an entry that says the thing the other six entries cannot.
